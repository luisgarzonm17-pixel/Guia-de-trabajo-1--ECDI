f(y) = 0 
luego de ello analizamos el signo de y´ a cada lado de cada punto. 

a) y´ = y(3-y)(y-2) 
los puntos criticos son: 
y(3-y)(y-2) = 0
por lo tanto: 
y = 0, y = 2, y = 3
